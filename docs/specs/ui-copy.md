# 界面文案规范 v1（2026-11-07）

适用于整个程序，《docs/specs/wizard.md》里的文案也按本规范统一。实现时**只能照抄本文和规格里的文案**，需要新增文案时先在审阅包里提问。

## 一、用语表（全程序统一）

| 统一用 | 不再使用 | 说明 |
|---|---|---|
| 你 | 您、本人 | 语气友好直接，和主窗口一致 |
| 加水印 | 嵌入水印、添加水印 | 和主窗口选项卡名一致 |
| 检查（向导里）／检测（选项卡名） | 读取水印、核对 | |
| 编号 | ID、标识 | 显示格式保持 `0x1a2b3c4d` |
| 副本 | 拷贝、复制品 | |
| 接收人 | 收件人、对象 | |
| 备注 | 渠道备注、渠道 | 界面上统一写“备注”；数据字段名 `channel` 不变 |
| 选择 | 选取、选定 | |
| 停止 | 中止 | |
| 使用这把密钥／移除（不删除文件） | 载入、卸载 | |
| 密钥指纹 | 指纹 | 第一次出现时解释：用来核对是不是同一把密钥 |
| BlindMark | blindmark（作为显示名称时） | 程序名称一律写 BlindMark；命令名和文件名仍然用小写 blindmark |

**写法规则**
- 句子用中文全角标点。按钮文字不加句号。打开新对话框的按钮以“…”结尾。
- 按钮写成“动词 + 宾语”。
- 错误提示分三层：发生了什么 → 为什么（可省略）→ 现在可以怎么做。技术细节放进“详细信息”，或者只写进日志。
- 少用“错误”“失败”。部分成功时写“已完成 8 张，2 张没有处理”。
- 不写“请单击‘下一步’继续”这一类重复按钮作用的话。
- 正文里不出现 PSNR、z 值、阈值、仿射、错切等术语。它们只能出现在“详细信息”或“技术详情”里。

## 二、UserError 的中文提示

| 情况 | message |
|---|---|
| 登记表和密钥不配对 | 这个登记表属于另一把密钥（密钥指纹 {fp}），不能和当前密钥一起使用。请换一个登记表文件夹，或改用对应的密钥。 |
| 登记表打不开 | 无法打开登记表 {dir}。请检查这个文件夹是否存在、是否可以写入。 |
| 图片打不开 | 无法打开 {name}：文件可能已损坏，或者不是支持的图片格式。 |
| 输出文件夹不可写 | 无法保存到 {dir}。请换一个文件夹，或检查这个文件夹是否只读。 |
| 密钥文件无效 | {name} 不是 BlindMark 的密钥文件。 |
| 时间戳服务连不上 | 暂时没能获取时间戳（无法连接 {host}）。副本已经生成，可以稍后在登记表中重试。 |
| 其他意外错误 | 处理 {name} 时出了问题。点“详细信息”可以查看原因。 |

## 三、向导文案（逐页）

### 欢迎页
- 标题：欢迎使用 BlindMark
- 副标题：给图片加上看不见的水印，证明图片是你的
- 正文：
  > BlindMark 会在图片里加入肉眼看不见的编号。图片被转发、截图或压缩后，通常仍然能读出这个编号，用来证明图片是你的，并查出是从哪一份副本流出去的。
  >
  > 这个向导会带你完成：
  > · 首次设置：创建密钥、选择登记表的位置
  > · 给图片加水印
  > · 分发给多人：每人一份独立编号的副本
  > · 检查可疑图片
  >
  > 所有处理都在你的电脑上完成，图片不会上传。
- 复选框：启动时显示此向导

### 选择任务页
- 标题：选择要做的事
- 副标题：以后随时可以按 F1 回到这里。
- 单选项（粗体标题 + 灰色说明）：
  1. 完成首次设置 —— 创建密钥，并选择登记表的保存位置。（已有密钥时改为：**更换密钥或登记表** —— 改用另一把密钥，或换一个登记表文件夹。）
  2. 给图片加水印 —— 为每张图片生成一份带编号的副本，编号会记进登记表。
  3. 分发给多人 —— 给每位接收人各生成一份编号不同的副本，泄露后能查出是谁。
  4. 检查可疑图片 —— 看图片里有没有你的水印，以及它是哪一份副本。

### S1 密钥
- 标题：创建或选择你的密钥
- 副标题：只有用这把密钥，才能读出你加的水印
- 单选项 1：新建一把密钥（推荐）；下方显示“保存位置：{path}”，旁边按钮「更改位置…」
- 单选项 2：使用已有的密钥文件；旁边按钮「浏览…」，选好后显示“{path}”和“密钥指纹：{fp}（用来核对是不是同一把密钥）”
- 红字提示：丢了密钥，就再也读不出已加的水印。设置完成后请立即备份。
- 位置已有密钥时的询问：这里已经有一把密钥（密钥指纹 {fp}）。要直接使用它吗？ 按钮：「使用这把密钥」「换个位置」
- 页面内错误：
  - 请先新建一把密钥，或选择已有的密钥文件。
  - {name} 不是 BlindMark 的密钥文件。
  - 无法在 {dir} 创建密钥。请换一个位置。

### S2 登记表
- 标题：选择登记表的保存位置
- 副标题：登记表记录每个编号对应哪张原图、发给了谁
- 正文：它和密钥一样重要，建议放在会定期备份的位置。
- 标签：位置；按钮「浏览…」
- 状态行（三选一）：
  - 这是一个新的登记表。
  - 已有登记表，共 {n} 条记录，与所选密钥匹配。
  - （红字）这个登记表属于另一把密钥（密钥指纹 {fp}），不能和所选密钥一起使用。
- 提交：保存设置／保存并继续

### S3 完成页（首次设置）
- 标题：设置完成
- 副标题：现在备份你的密钥
- 正文：把密钥文件复制到 U 盘或密码管理器里。请不要发给任何人。
- 按钮：「备份密钥…」「备份登记表…」；默认文件名 `blindmark-key-backup-YYYYMMDD.key`
- 提示：以后可以在主窗口的“设置”选项卡里随时备份。

### 选择图片页（E1 / D1 / C1）
- 标题：选择要加水印的图片／选择要分发的图片／选择要检查的图片
- 副标题：可以一次添加多张，也可以添加整个文件夹
- 空列表提示：把图片拖到这里，或点“添加图片…”
- 按钮：「添加图片…」「添加文件夹…」「移除」；C1 另有「粘贴截图（Ctrl+V）」
- 列：文件名、尺寸、位置
- 页面内错误：请至少添加一张图片。

### E2 加水印选项
- 标题：设置这批图片的水印
- 副标题：这些选项只用于这一次，不会改变你的默认设置
- 备注（可选）：输入框内的灰色提示为“例如：发到微博、给甲方的终稿”
- 保存到：● 和原图放在同一文件夹　○ 指定文件夹：[　　] 「浏览…」
- 格式：● PNG（推荐，画质无损）　○ JPEG（质量 95）
- 高级 ▸ 水印强度：[滑块] {档位}（{数值}）。说明：越强越容易在压缩、截图后读出，但画面改变也越明显。档位：低于 2.0 为“较弱”，2.0–2.8 为“标准”，高于 2.8 为“较强”。
- 提交：开始加水印

### D2 选择接收人
- 标题：选择要发给谁
- 副标题：每位接收人都会拿到一份编号不同的副本
- 左侧分组树的第一项：全部接收人；不属于任何分组的人放在“未分组”下面
- 列：接收人、分组、备注
- 按钮：「新建接收人…」「新建分组…」
- 汇总行：已选 {k} 人 × {m} 张图片 = 将生成 {n} 份
- 页面内错误：请至少选择一位接收人。
- 新建接收人对话框：标题“新建接收人”；字段：姓名、分组（下拉框，含“未分组”）、备注（可选）；按钮「添加」「取消」；错误“请填写姓名。”
- 新建分组对话框：标题“新建分组”；字段：名称、上级分组（下拉框，含“无（作为一级分组）”）；按钮「创建」「取消」；错误“请填写分组名称。”“分组最多两级。”

### D3 分发选项
- 标题：设置副本的保存方式
- 保存到：[　　] 「浏览…」
- ● 每位接收人一个文件夹（推荐）　○ 都放在一起，文件名后加上接收人姓名
- 格式：同 E2
- □ 申请可信时间戳。说明：会联网，只把这批副本的摘要发给时间戳服务（{host}），图片和密钥不会离开你的电脑。可以证明这批副本在今天之前就已经存在。
- 提交：生成 {n} 份

### C1 补充
- 提交：开始检查

### 进度页（E3 / D4 / C2）
- 标题：正在加水印…／正在生成副本…／正在检查…
- 进度文字：正在处理 {name}（{done}/{total}）…
- “取消”按钮的作用是停止；确认框：要停止吗？已经处理好的图片会保留。 按钮：「停止」「继续处理」

### E4 完成页（加水印）
- 标题：已为 {n} 张图片加上水印；有未完成时写：已完成 {n} 张，{m} 张没有处理；被停止时写：已停止：完成 {n} / {total} 张
- 结果行：{name} → 编号 {id}，保存为 {output}；没处理的那一行：{name} 没有处理：{message}
- 按钮：「打开所在文件夹」「在登记表中查看」
- 教学提示：以后可以直接在主窗口的“加水印”选项卡里拖入图片完成这一步。 按钮：「转到“加水印”选项卡」

### D5 完成页（分发）
- 标题：已为 {k} 位接收人生成 {n} 份副本
- 结果行：{recipient} — {output} — 编号 {id}
- 时间戳行：时间戳已获取。／暂时没能获取时间戳，可以稍后在登记表中重试。
- 按钮：「打开输出文件夹」「在登记表中查看」
- 教学提示：以后可以在“加水印”选项卡里选好图片，点“分发给多人…”直接完成。 按钮：「转到“加水印”选项卡」

### C3 完成页（检查）
- 标题（按结果选一个；有多张图时按最好的一张）：这张图片是你的／找到了你的水印，但画面对不上／没有找到你的水印
- 结果行：
  - {name}：是你的图片（编号 {id}，发给 {recipient}，{date} 登记）。没有接收人时：（编号 {id}，备注“{channel}”，{date} 登记）
  - {name}：找到了你的水印（编号 {id}），但画面和登记的原图对不上，可能被大幅改动过，也可能是有人把水印移到了别的图上
  - {name}：可能有你的水印，但图片损坏太严重，读不出编号
  - {name}：没有找到你的水印
- 没找到时的补充：没找到不代表这张图一定不是你的：图片可能被缩得太小、被重绘，或者是用另一把密钥加的水印。
- 按钮：「导出检测报告…」「在登记表中查看」
- 教学提示：以后可以在“检测”选项卡里直接按 Ctrl+V 粘贴截图。 按钮：「转到“检测”选项卡」

## 四、菜单、状态栏、设置页
