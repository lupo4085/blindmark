# 主窗口规格（v1 定稿，2026-11-21）

适用于 v0.3 的图形界面，取代旧的 `wizard.md` 和 `ui-copy.md`。所有界面卡（P-3、U-1～U-6）都以本文为准；本文没写的，按第 0 节的通用规则处理，拿不准就在审阅包「问题」里提出，不要自己发挥。

依据：微软《Windows User Experience Interaction Guidelines》（UX Guide，Windows 7 版，经典桌面程序的官方规范）：https://learn.microsoft.com/en-us/windows/win32/uxguide/guidelines ，以及它的检查清单 https://learn.microsoft.com/en-us/windows/win32/uxguide/top-violations 。

---

## 0. 通用规则

**0.1 用语表**（全程序统一，别处不许换说法）
| 用这个 | 不用 |
|---|---|
| 加水印 | 嵌入、打水印 |
| 检测 / 检查 | 识别、扫描 |
| 编号 | ID、水印 ID |
| 登记表 | 数据库、注册表 |
| 密钥 / 密钥指纹 | 私钥、key |
| 接收人 / 分组 | 收件人、联系人 |
| 副本（分发时每人一份） | 拷贝、复制品 |
| 批次 | 任务、作业 |
| 可信时间戳 | 时间戳证书 |
| 备注 | 渠道 |
| 没有完成 | 失败、错误 |
| 水印偏弱 / 装不下水印 | 检测失败 |
| 停止 | 取消（处理中的按钮） |

**0.2 交互规则**
1. **提交按钮不禁用**。条件不够时，点了以后在按钮左边用红字说明缺什么，一次只说第一条。用户改动相关输入后红字消失。
2. **校验就地提示**，不弹对话框。弹窗只用在：要用户确认的不可撤销操作（归档、处理中关窗口）、启动时设置文件读不出来、显示助记词。
3. **结果留在原处**：处理完的结果一直显示，直到用户清空或开始下一批。状态栏只放一句总结。
4. **处理中**：会影响这一批的输入全部禁用，只有「停止」可用；进度条加一行文字说明正在做什么。停止在两份之间生效，已经完成的保留。
5. **如实报告**：读不回的不算完成；偏弱的算完成但标出来；不用“失败”“错误”这类字眼，用“没有完成”，并说明原因和办法。
6. **不覆盖文件**：输出同名时自动换名；界面上不出现“覆盖”选项。
7. **路径显示完整**：列表里放不下时省略中间部分，选中后详情框里显示完整路径。
8. **键盘**：每个按钮有访问键或快捷键；Tab 顺序从上到下、从左到右；Enter 触发当前页的主按钮。
9. **空状态**：列表空着时，在列表中间用灰字说明下一步做什么（具体文字见各节）。
10. **记住与不记住**：记住窗口大小、上次的选项卡、默认参数、“分发给多人”的开关；**不记住**“申请可信时间戳”（每次都是不勾）和勾选的接收人（重启后清空）。

**0.3 弹窗的标题和按钮**：标题统一是 `blindmark`；按钮用动词（「归档」「显示」），不用「是/否」。

## 1. 主窗口框架

### 1.1 选项卡
四个：**加水印**、**检测**、**登记表**、**设置**，快捷键 Ctrl+1～Ctrl+4（编号不变，不需要迁移）。

### 1.2 菜单
| 菜单 | 项目 |
|---|---|
| 文件 | 添加图片…（Ctrl+O） / 添加文件夹… / — / 检测图片…（Ctrl+D） / 从剪贴板检测（Ctrl+V） / — / 退出 |
| 编辑 | 移除所选（Del） / 清空列表 / — / 复制检测报告（Ctrl+Shift+C） |
| 视图 | 加水印 / 检测 / 登记表 / 设置 / — / 刷新登记表（F5） |
| 工具 | **首次设置…** / — / 新建密钥… / 选择密钥文件… / — / 打开登记表文件夹 / 备份登记表… / 导出登记表为 CSV… |
| 帮助 | 许可证… / 关于 blindmark… |

变化：“帮助 → 开始使用…（F1）”去掉，向导入口改为“工具 → 首次设置…”。F1 不再分配。

### 1.3 状态栏
四格：`{最近一条消息}` | `密钥 {指纹}` 或 `未加载密钥` | `登记表 {n} 条` 或 `登记表不可用` / `无登记表` | `v{版本}`。

### 1.4 标题
`blindmark 盲水印`；设了 `BLINDMARK_DATA_DIR` 时为 `blindmark 盲水印（测试数据：{路径}）`。

### 1.5 启动
- 没有密钥：主窗口出现后自动打开首次设置向导。
- 有密钥：不弹向导，打开“启动时打开”设置的选项卡（或上次的）。
- 首次设置被关掉、仍然没有密钥：主窗口照常可用；加水印、检测、登记表三个选项卡显示“还没有完成首次设置”的提示（第 7 节）。

| S2 | 选择登记表的保存位置 | 位置 + 浏览；下方实时状态三种（新的登记表 / 已有 N 条且与密钥匹配 / 属于另一把密钥） |

## 3. 加水印选项卡（加水印和分发合在一起）

### 3.1 两种情况
- **普通加水印**：“分发给多人”不勾。每张图生成一份带编号的副本。
- **分发给多人**：勾上后右侧出现接收人栏。每张图给每位勾选的接收人各生成一份编号不同的副本。
- 开关记住上次的状态。

### 3.2 布局

│ 文件名      尺寸    大小   位置    │ │┌分组──────┐┌接收人────────────────────┐│
│                                   │ ││全部接收人││☑ 姓名   分组路径   备注    ││

- 勾“分发给多人”时，图片列表和接收人栏左右各占一半；不勾时图片列表占满宽度。
- 上半部分（图片、接收人）和下半部分（结果、详情）高度约 55% / 45%，窗口缩放时一起伸缩。
- 「编辑…」「归档」两个按钮在 U-4 加；U-1 先只有两个新建按钮。

### 3.3 图片列表
- 列：文件名、尺寸、大小、位置。**不再有“状态”列**，处理结果统一放到下面的结果列表。
- 添加：「添加图片…」「添加文件夹…」、拖放、菜单。重复的文件不重复添加。
- 空状态：`把图片拖到这里，或点“添加图片…”`
- 处理中不能增删。

### 3.4 接收人栏
- 分组树：全部接收人 / 未分组 / 一级分组（下挂子分组），全部展开。默认选中“全部接收人”。
- 名单：三列（姓名、分组路径、备注），带复选框。勾选状态由页面状态决定：切换分组、切换选项卡、关掉“分发给多人”再打开，勾选都保留；**重启程序后清空**（不记住，避免下次误发）。
- 新建接收人、新建分组：对话框见第 8 节。新建的接收人自动勾上；新建的分组自动选中。
- 空状态：名单里一个人都没有：`还没有接收人。点“新建接收人…”添加第一位。`；所选分组里没有人：`这个分组里还没有人。`
- 名单打不开：树、名单和按钮都禁用，名单区域红字 `接收人名单（recipients.json）打不开：文件可能已损坏。`
- 登记表文件夹变了（设置页更改、首次设置完成）：重新打开名单，清空勾选。

### 3.5 选项
| 控件 | 普通 | 分发 | 初始值 |
|---|---|---|---|
| 保存到 | 可用；空 = 原图旁边（输入框灰字提示 `留空 = 保存在原图旁边`） | 可用；**不能为空**（校验见 3.6） | 设置里的默认输出文件夹 |
| 每位接收人一个文件夹 / 都放在一起 | 禁用 | 可用 | 每位接收人一个文件夹 |
| 备注 | 可用（下拉记最近用过的） | 禁用，灰字 `分发时登记表记录的是接收人` | 上次的备注 |
| 格式 | 可用 | 可用 | 设置里的默认值 |
| 强度 | 可用 | 可用 | 设置里的默认值 |
| 申请可信时间戳 | 可用 | 可用 | 不勾（不记住） |

这里改的选项只用于这一批，不改设置里的默认值（设置页才改默认值）。

### 3.6 汇总行、主按钮和校验
| | 普通 | 分发 |
|---|---|---|
| 汇总行 | `{m} 张图片` | `已选 {k} 人 × {m} 张图片 = 将生成 {n} 份` |
| 主按钮 | 「开始加水印」 | 「生成 {n} 份」（n 为 0 时是「生成」） |
| 校验顺序（红字） | `请至少添加一张图片。` | `请至少添加一张图片。` → `请至少选择一位接收人。` → `请选择保存位置。` |

主按钮不禁用。还没有完成首次设置时，整个选项卡换成第 7 节的提示。

### 3.7 处理中
- 禁用：图片列表和它的按钮、“分发给多人”开关、接收人栏、全部选项、主按钮。「停止」可用。
- 进度条按份数前进；进度文字：普通 `正在处理 {文件名}（{done}/{total}）…`；分发 `正在处理 {文件名} → {接收人}（{done}/{total}）…`；申请时间戳时 `正在申请可信时间戳…`。
- 结果列表随处理逐行增加。
- 处理中切换到别的选项卡可以，回来时进度照常显示；处理中关窗口：确认框 `正在处理，还有 {total-done} 份没做完。关掉窗口会停止处理，已经完成的会保留。` 按钮「停止并关闭」「继续处理」。

### 3.8 结果
**结果列表每一行**（普通一行一张图；分发一行一份副本）：
| 情况 | 结果列 | 选中后详情框 |
|---|---|---|
| 成功 | `✓ 0x{id} → {输出文件名}` | 普通：`编号 0x{id}，已保存为 {完整路径}。` 分发：`发给 {接收人}（{分组路径}）。编号 0x{id}，已保存为 {完整路径}。` |
| 偏弱 | `⚠ 0x{id} → {输出文件名}（水印偏弱）` | 成功那句，再加：`水印能读出，但图片再被压缩或截图后可能读不出。直接发原文件（PNG）没有问题；如果对方可能转发或截图，换一张内容更丰富的图更稳妥。` |
| 读不回 | `✗ 没有保存：装不下水印` | `{文件名} 大面积是纯色，装不下水印：加完以后读不回来，所以没有保存，也没有登记。换一张内容更丰富的图，或者裁掉纯色区域再试。` 分发时再加：`同一张图的其他副本也一样。` |
| 其他没完成 | `✗ {message}` | `{message}` 换行 `详细信息：{detail}` |

**结果汇总行**（在结果列表上方；单位：普通用“张”，分发用“份”）：
- 全部成功：普通 `已为 {n} 张图片加上水印`；分发 `已为 {k} 位接收人生成 {n} 份副本`
- 有偏弱或没完成：`已完成 {n} {单位}` + `，其中 {w} {单位}水印偏弱` + `，{f} {单位}没有完成`
- 被停止：`已停止：完成 {done} / {total} {单位}`
- 全部没完成：`没有完成：{f} {单位}都没有加上水印`
- 右边两个按钮：「打开输出文件夹」（多个文件夹时打开第一个成功副本所在的文件夹）、「在登记表中查看」（切到登记表，按批次视图选中这一批）。没有任何成功时两个都禁用。

**状态栏**：和结果汇总行同一句。

**时间戳行**（勾了才显示）：
| 情况 | 显示 |
|---|---|
| 申请中 | `正在申请可信时间戳…` |
| 成功 | `时间戳已获取（{本地时间 YYYY-MM-DD HH:MM}）` |
| 没获取到 | `{message}`（V3-4 的文案）+ 「重试」 |
| 重试中 | `正在重试…`（「重试」禁用） |
| 没有成功的副本 | `没有成功的{单位}，没有申请时间戳` |

**处理完以后**：输入全部恢复可用；图片、勾选、选项都保留，可以改一改再来一批（新批次，不覆盖已有文件）。结果保留到下次开始或清空图片列表。

## 4. 检测选项卡
现有布局不变（打开图片… / 从剪贴板粘贴 / 结论横幅 / 信息表 / 登记时的样子 / 技术细节 / 复制报告 / 导出证据…）。U-3 增加：
- 信息表在“图片编号”下面加三行（没有就不显示这一行）：`接收人`（姓名）、`分组`（分组路径）、`批次`（批次号和时间）。“渠道”改名为“备注”。
- 结论横幅“确认：这是你的图片”的说明行，有接收人时改为：`这是发给 {接收人} 的那一份（编号 0x{id}，{日期} 登记）。画面与登记的原图相符（相似度 {s}%）。`
- 没有密钥：显示第 7 节的提示。

## 5. 登记表选项卡
顶部加一个切换：**● 按编号　○ 按批次**（记住上次选择）。

### 5.1 按编号（现有列表加接收人）
- 列：编号、原始文件、**接收人**、备注（原“渠道”）、登记时间、尺寸、强度。没有接收人的显示 `—`。
- 搜索框灰字：`按编号、文件名、备注或接收人搜索`。
- 右侧详情区加几行（没有就不显示）：`接收人：{姓名}（{分组路径}）`、`批次：{批次号}`、`文件 SHA-256：{哈希}`、`自检：正常 / 水印偏弱`。

### 5.2 按批次（新）
- 上半部分批次列表，列：时间、类型（`加水印` / `分发`）、份数、接收人数（加水印批次显示 `—`）、时间戳。按时间倒序。
- 时间戳列：`已获取（{时间}）` / `没有获取到` / `没有申请`。
- 早于 v0.3、没有批次号的记录，归在一行 `早期记录（没有批次）`，时间戳列 `—`。
- 选中一批，下半部分显示这一批的副本（列：编号、原始文件、接收人、输出文件、自检），以及按钮：
  - 时间戳“没有获取到”：「重试申请时间戳」
  - 时间戳“没有申请”：「申请可信时间戳」，旁边灰字说明会联网（同 3.2 的说明）。需要核心支持：按登记表里这一批的记录生成清单再申请（U-3 前的核心卡）。
  - 时间戳“已获取”：「打开时间戳文件夹」、「复制核验命令」（复制 `timestamps/README.txt` 里的 openssl 命令，填好这一批的文件路径）
  - 都有：「打开输出文件夹」
- 申请或重试中：按钮禁用，文字 `正在申请…`；结束后刷新这一行。
- 空状态：`还没有批次。加水印或分发以后会出现在这里。`

## 7. 还没有完成首次设置时
加水印、检测、登记表三个选项卡，在没有密钥或登记表不可用时，整个页面换成居中的一行字和一个按钮：
- 没有密钥：`还没有完成首次设置。` 「开始设置…」（打开首次设置向导）
- 有密钥但登记表不可用：`登记表无法使用：{原因}` 「到设置里更换登记表…」（切到设置选项卡）
