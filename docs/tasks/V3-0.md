# V3-0 把 alpha 分支的核心代码移植到 main（不带界面）

- **基线分支**：`main`（**前提**：`t-w-ui` 已经由 Lupo 合并进 main），工作分支 `t-v3-0`
- **预计**：S
- **目标**：把接收人簿、分发、时间戳三个核心模块搬到 main 上。alpha 分支的界面代码（`distdialog.rs`、`setpage.rs`、`embed.rs`、`config.rs`、`mod.rs` 的改动）**一行都不搬**，分发界面以后按 W-5 在向导里重做。

## 为什么不用 rebase
alpha 分出去以后，main 上的向导、`jobs.rs`、设置页都重写了，rebase 会在界面文件上大面积冲突，而这些界面代码反正要扔掉。核心文件在 main 上没有被改过，可以原样拿过来。

## 步骤（照做，不要换方法）
1. `git switch -c t-v3-0 main`
2. 原样取出 alpha 版本的 5 个文件：
   ```
   git checkout origin/alpha -- src/recipients.rs src/distribute.rs src/timestamp.rs src/registry.rs src/bin/cli.rs
   ```
   这 5 个文件在 alpha 分出去以后，main 上没有改过（已核对），所以不会丢掉 main 的改动。
3. `src/lib.rs`：在模块列表里加上 `pub mod distribute;`、`pub mod recipients;`、`pub mod timestamp;`。保留 main 已有的 `pub mod jobs;`。其他不动。
4. `Cargo.toml`：在 `[dependencies]` 里加一行 `ureq = "2.12"`（和 alpha 一致）。**版本号不动。**
5. 运行 `cargo build --release`，让 `Cargo.lock` 更新，并把 `Cargo.lock` 一起提交（alpha 漏提交过，见现状审阅第 6 条）。
6. 自检两条命令都通过后提交：`V3-0: port recipients, distribute, timestamp core from alpha`。

## 不要做
- 不要修 alpha 的已知问题（时间戳默认开启、哈希、recipient_id 等），那是 V3-2、V3-3、V3-4 的事。这张卡只搬代码。
- 不要碰 `src/win/` 下任何文件，不要碰 `.github/`。

## 验收
- [ ] `git diff --stat main..t-v3-0` 只有这几个文件：`src/recipients.rs`、`src/distribute.rs`、`src/timestamp.rs`、`src/registry.rs`、`src/bin/cli.rs`、`src/lib.rs`、`Cargo.toml`、`Cargo.lock`
- [ ] `cargo test --release --lib` 通过（应包含 recipients 和 timestamp 的测试）
- [ ] `cargo check --features win32-check --bins` 通过
- [ ] `blindmark-cli recipients list --registry <空文件夹>` 能运行，不崩溃
