## 2. src/win/start.rs 的结构
```rust
pub enum Task { Setup, Embed, Distribute, Check }

pub enum WizardOutcome { Closed, SettingsChanged { key_path: PathBuf, registry_dir: PathBuf }, ShowTab(usize), ShowInRegistry(Vec<u32>) }
pub struct WizardContext { pub cfg: Settings, pub key: Option<Vec<u8>>, pub embed_files: Vec<PathBuf> }
pub struct WizardResult { pub outcome: WizardOutcome, pub show_on_start: bool }

pub fn run(owner: HWND, ctx: WizardContext) -> WizardResult;
```
说明：`wizard.md` 第 5 节写的是“`show_start_wizard` 由向导直接写入设置”，这里改为通过 `WizardResult` 交还给 App、由 App 保存。以本卡为准，这样才符合 ARCHITECTURE.md 第 1 条。

### 2.1 状态所有权（必须照这样写）
```rust
struct St {
    ctx: WizardContext,
    task: Task,
    history: Vec<i32>,     // 已经访问过的页面的资源 ID，“上一步”时从这里弹出
    cur: i32,              // 当前页面的资源 ID，在 PSN_SETACTIVE 里更新
    show_on_start: bool,
    outcome: WizardOutcome,
    bmp: HBITMAP, white: HBRUSH,
    panicked: bool,
}
```
- `run` 里写 `let raw = Box::into_raw(Box::new(St { .. }));`。每个 `PROPSHEETPAGEW` 的 `lParam` 都设成 `raw as isize`。
- 在每页的 `WM_INITDIALOG` 里，`lp` 是 `*const PROPSHEETPAGEW`。从中取出 `lParam`，写进 `SetWindowLongPtrW(h, GWLP_USERDATA, ..)`。
- 写一个 `fn st(h: HWND) -> Option<&'static mut St>`，从 `GWLP_USERDATA` 读出状态；读到 0 时返回 None。**不准使用 thread_local。**
- `PropertySheetW` 返回之后，`let st = unsafe { Box::from_raw(raw) };`。整个文件里只能有这一处 `from_raw`。然后释放 GDI 对象，把 `WizardResult { outcome: st.outcome, show_on_start: st.show_on_start }` 交回去。

### 2.2 panic 保护
- 所有页面过程都写成：
  `unsafe extern "system" fn page_x(h, msg, wp, lp) -> isize { guard(h, || page_x_impl(h, msg, wp, lp)) }`
- `guard` 用 `catch_unwind(AssertUnwindSafe(f))`，panic 时：
  1. 如果 `st(h).panicked` 已经是 true，直接返回 0。否则把它设为 true。
  2. 用 `eprintln!` 打出 panic 信息。
  3. 用 `MessageBoxW` 显示文案“向导遇到了意外问题，已经关闭。你的图片、密钥和登记表都没有受影响。”（图标用 `MB_ICONWARNING`）。
  4. `PostMessageW(sheet, PSM_PRESSBUTTON, PSBTN_CANCEL, 0)`。
  5. 返回 0。

### 2.3 页面跳转（替代旧向导里“PSN_SETACTIVE 返回 -1”的写法）
- 在 `PSN_WIZNEXT` 里：算出目标页 ID → `history.push(cur)` → `SetWindowLongPtrW(h, DWLP_MSGRESULT, target)` → 返回 1。
- 在 `PSN_WIZBACK` 里：如果 `history` 能弹出一个 ID，就把 `DWLP_MSGRESULT` 设成它；如果是空的，就设成 -1。然后返回 1。
- 在 `PSN_SETACTIVE` 里：`cur = 本页 ID`，按本页需要设置按钮，返回 0。**不准**在 `PSN_SETACTIVE` 里用返回 -1 的方式跳页。

## 3. 各页
文案一律照抄 ui-copy。
- **210 欢迎页**：标题、副标题、正文，底部放复选框“启动时显示此向导”。复选框初始状态 = `ctx.cfg.show_start_wizard`。**复选框一变化**（处理 `BN_CLICKED`），就立刻写入 `st.show_on_start`。按钮：只有“下一步”，没有“上一步”。点“下一步”的目标页是 211。
- **211 选择任务页**：4 个单选项，每项一个粗体标题，下面跟一段灰色说明；第 1 项的文字要根据 `ctx.key.is_some()` 来切换。默认选中：`ctx.key.is_none()` 时选第 1 项，否则选第 2 项。离开这一页再回来时，保持上次选的那一项。点“下一步”时：把选中项写入 `st.task`，目标页 219。
- **219 占位页**：按 `st.task` 显示对应的正文。按钮只有“上一步”和“完成”。点“完成”时 `outcome = Closed`。

## 4. 主窗口（mod.rs / config.rs）
- `Settings` 新增 `#[serde(default = "yes")] pub show_start_wizard: bool`，默认值 true。删除 `is_first_run`。
- 新增 `cmd::START: u16 = 107`。在“帮助”菜单最上面加一项「开始使用…\tF1」，下面加一条分隔线。加快捷键 `VK_F1 → cmd::START`。
- 旧的“文件 → 使用向导… Ctrl+W”**暂时保留**，W-4 时删除。
- 新增 `App::open_start()`：
  1. 组装 `WizardContext`：`cfg` 用 `self.cfg.clone()`，`key` 用 `self.key.clone()`，`embed_files` 用 `embed::files(self)`。如果没有现成的函数，就在 `embed.rs` 里加一个只读的 `pub fn files(a: &App) -> Vec<PathBuf>`，这是唯一允许改 `embed.rs` 的地方。
  2. 调用 `start::run`。
  3. 如果 `show_on_start` 和原值不同，就写入 `self.cfg` 并 `save()`。
  4. **始终**调用 `self.load_key_and_registry(false)`。
  5. 处理 `outcome`：`Closed` 什么都不做；其余三种在本卡里还不会出现，先写成 `_ => {}`，并加上 TODO 注释写明“W-2/W-3 接上”。
- 在 `run()` 里，主窗口显示出来、`load_key_and_registry` 执行之后：如果 `cfg.show_start_wizard` 为 true，就调用 `a.open_start()`；如果为 false 并且 `a.key.is_none()`，就在状态栏显示 ui-copy 第四节的那句提示。
