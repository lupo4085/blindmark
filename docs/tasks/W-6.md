- **范围**：`src/win/start.rs`（只改 D2）、`src/win/recdlg.rs`、`src/win/regpage.rs`、`src/win/detect.rs`、`src/jobs.rs`（只在 `DetectResult` 里加字段）、`assets/blindmark.rc.in`（如需）

## 1. D2 补全管理功能
线框在 W-5 的基础上，按钮行改成：
```
[新建分组…] [重命名分组…]        [新建接收人…] [编辑…] [归档]
                                  □ 显示已归档的人
```
- 「编辑…」：名单里选中一行（高亮，不是勾选）时可用。打开 260，标题“编辑接收人”，确定按钮“保存”，初值取这个人。成功后 `book.update_recipient`，刷新名单，勾选状态不变。
- 「归档」：选中一个未归档的人时可用。先弹确认框（`task_dialog`，按钮「归档」「取消」）。确认后 `book.set_archived(id, true)`，并且**从 `d_checked` 里去掉**这个人。
- 「显示已归档的人」：勾上后名单用 `list(filter, true)`。已归档的人灰色显示（`NM_CUSTOMDRAW` 改文字颜色为 `COLOR_GRAYTEXT`），姓名后加“（已归档）”，复选框不能勾（在 `LVN_ITEMCHANGING` 里拦掉）。选中已归档的人时，「归档」按钮文字变成「恢复」，点了直接恢复，不用确认。
- 「重命名分组…」：树上选中真实分组时可用。打开 261，`show_parent = false`，标题“重命名分组”，按钮“保存”。成功后刷新树并保持选中。
- `Book` 返回错误时，按 W-5 第 5 节的方式带着错误重新打开对话框。

## 2. 检测结果带上接收人
`jobs::DetectResult` 新增：
```rust
pub recipient: Option<String>,        // 登记条目里的 recipient_name
pub recipient_group: Option<String>,  // 登记条目里的 group_name
```
在 `DetectContext::detect` 里，找到编号并且登记表里有这一条时填上。**用条目里记录的名字**（分发当时的名字），不去接收人名单里查现在的名字：证据要以当时的记录为准。

## 3. 检测选项卡
- 结果表在“编号”右边加一列“接收人”，没有时显示“—”。
- “找到你的水印”横幅的说明行：有接收人时按 ui-copy 第五节的句式。
- 导出的文字报告和“导出证据…”里的报告，在编号下面加一行 `接收人：{name}（{group}）`，没有就不加。

## 4. 登记表选项卡
- 在“渠道”列右边加一列“接收人”。（顺便把列名“渠道”改成“备注”，和 ui-copy 统一。）
- 搜索同时匹配 `recipient_name`。搜索框灰色提示按 ui-copy。
- 详情区按 ui-copy 加三行（接收人、分发批次、文件 SHA-256），字段为空的行不显示。
- 导出 CSV 时多三列：`recipient`、`batch_id`、`sha256_file`，加在最后，原有列的顺序不变。
