## 1. 两个对话框（`src/win/mnemonic.rs`）
同样用资源模板 + `DialogBoxParamW`，控件位置写在 `.rc` 里。对话框过程用 `guard` 包住。
```rust
/// 显示 24 个词。words.len() 必须是 24。
pub fn show_words(owner: HWND, words: &[String], fingerprint: &str);
/// 让用户输入助记词。只解析，不写文件。成功返回 32 字节密钥。
pub fn ask_words(owner: HWND) -> Option<[u8; 32]>;
```
**262 显示**（宽约 300、高约 200）：加粗标题行、说明（多行静态文字）、正文用一个只读的静态控件，字体用 `Consolas`（找不到时用系统等宽字体），文字按 4 列 × 6 行排好（按列排：第一列 1–6，第二列 7–12……），每格宽度用空格补齐到相同长度。按钮「我已抄好」。**没有复制按钮**；正文控件也不能选中文字（用 `SS_LEFT` 静态控件，不用编辑框）。

**263 恢复**（宽约 280、高约 170）：说明、多行编辑框（`ES_MULTILINE | ES_AUTOVSCROLL | WS_VSCROLL`，等宽字体）、计数行、红字错误行、「恢复」「取消」。
- 计数：编辑框每次 `EN_CHANGE` 时调用 `keys::count_words`（V3-5 已提供）。
- 点「恢复」：调用 `keys::key_from_words`。失败 → 错误行显示 `jobs::words_error_message(&e)`（V3-5 已提供，不要在界面里再写一遍文案），不关闭。成功 → 关闭并返回密钥。
- 本卡**不改** `keys.rs` 和 `jobs.rs`。
- 输入框的内容不写日志、不写任何文件。对话框关闭前用 `SetWindowTextW(edit, "")` 清空。

## 2. 设置页
“密钥”一组加两个按钮：「显示助记词…」「用助记词恢复…」。
- 「显示助记词…」：没有在用的密钥时禁用。点了先弹确认框（ui-copy），选「显示」后调用 `jobs::key_words`：失败（长度不对）弹提示；成功打开 262。
- 「用助记词恢复…」：`ask_words` → 弹“另存为”（默认文件夹 `config::app_dir()`，默认文件名 `blindmark.key`）→ `jobs::write_key_bytes(&k, path)`。成功后**通过 App** 把 `cfg.key_path` 改成新路径、保存设置、重新加载密钥和登记表，状态栏按 ui-copy。失败（目标已有另一把密钥）弹提示，不改设置。

## 3. 向导
**S1**：在现有两个单选项下面加第三个“用助记词恢复密钥”，右边按钮「输入助记词…」（只有选中这一项时可用）。
- `KeyChoice` 加一个变体 `Restore([u8; 32])`。点按钮 → `ask_words` → 成功时选中这一项，并在下方显示“已识别，密钥指纹 {fp}”。
- 选中这一项但还没识别成功就点下一步 → 红字“请先输入助记词。”，停留。
- 密钥保存位置沿用“新建”那一项的位置控件（默认 `%APPDATA%\blindmark\blindmark.key`，「更改位置…」）。选“恢复”时这组控件也要可用。
- S1 仍然不写磁盘。

**S2 提交**：在“按需生成密钥”那一步，`KeyChoice::Restore(k)` 时改为调用 `jobs::write_key_bytes(&k, path)`（V3-5 已提供），St 里不保存助记词原文。

**S3**：在「备份密钥…」右边加「抄写助记词…」，直接打开 262（不弹确认框）。提示行换成 ui-copy 第五节的新文字。
