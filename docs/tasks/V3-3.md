## 接口（照写签名，返回 `anyhow::Result`，错误信息用下面给的中文原文）
```rust
pub enum GroupFilter<'a> { All, Ungrouped, Group(&'a str) }

impl Book {
    /// dir 为空路径时报错“现在没有在用的登记表。”，不读不写。
    pub fn open(dir: &Path) -> Result<Book>;

    /// Group(一级分组)：包含它自己和它所有子分组里的人。Group(子分组)：只含这个子分组。
    /// 按姓名排序（`name.to_lowercase()` 比较，相同时按 id）。
    pub fn list(&self, filter: GroupFilter, include_archived: bool) -> Vec<&Recipient>;

    /// 一级分组在前，各自的子分组紧跟其后；同级按名称排序。
    pub fn groups_tree(&self) -> Vec<(&Group, Vec<&Group>)>;

    pub fn add_group(&mut self, name: &str, parent: Option<&str>) -> Result<Group>;
    pub fn rename_group(&mut self, id: &str, name: &str) -> Result<()>;
    pub fn add_recipient(&mut self, name: &str, group: Option<&str>, note: &str) -> Result<Recipient>;
    pub fn update_recipient(&mut self, id: &str, name: &str, group: Option<&str>, note: &str) -> Result<()>;
    pub fn set_archived(&mut self, id: &str, archived: bool) -> Result<()>;
}
```
- 删掉旧的 `recipients_in`（被 `list` 取代），`recipient_by_name_or_create` 保留（命令行在用）。
- `add_*` 改为返回克隆的值，不再返回引用（界面拿着引用不方便）。
- 每个修改函数成功后都调用 `save()`；失败时内存里的数据要回到修改前的样子（先在副本上改，保存成功再替换，或者保存失败时撤销）。

**ID 生成**：`r_` 或 `g_` 加 8 位小写十六进制随机数（`getrandom`），和现有 ID 重复就重新生成。旧 ID 不改。

**校验和错误原文**
| 情况 | 错误 |
|---|---|
| 姓名去掉首尾空白后为空 | 请填写姓名。 |
| 分组名为空 | 请填写分组名称。 |
| 在子分组下再建分组 | 分组最多两级。 |
| 分组 ID 不存在 | 找不到这个分组，可能已经被修改，请重新打开。 |
| 接收人 ID 不存在 | 找不到这位接收人，可能已经被修改，请重新打开。 |
| 读文件失败 / JSON 无效 | 接收人名单（recipients.json）打不开：文件可能已损坏。 |

同名接收人**允许**（两个“张三”在不同分组很常见），界面靠分组区分。

## 命令行
```
blindmark-cli recipients list   [--registry DIR] [--group ID] [--archived]
blindmark-cli recipients add    <姓名> [--group ID] [--note 文本] [--registry DIR]
blindmark-cli recipients edit   <ID> [--name ..] [--group ID|none] [--note ..] [--registry DIR]
blindmark-cli recipients archive <ID> [--undo] [--registry DIR]
blindmark-cli recipients group  <名称> [--parent ID] [--registry DIR]
blindmark-cli recipients rename-group <ID> <新名称> [--registry DIR]
```
`list` 每人一行：`ID<TAB>姓名<TAB>分组路径<TAB>备注`，归档的人在行尾加 `<TAB>已归档`。

## 测试
- 旧格式文件（用 V3-1 的 `tests/golden/recipients-v1.json`）读入、修改、保存、再读入，旧 ID 不变
- 新 ID 符合 `^[rg]_[0-9a-f]{8}$`；连续新建 500 个人没有重复
- `list(Group(一级))` 包含子分组的人；`list(Group(子))` 不含兄弟分组的人；`list(Ungrouped)` 只含没有分组的人；归档的人默认不出现
- `Book::open(Path::new(""))` 返回 Err，并且当前目录下**没有**出现 `recipients.json`
- 修改时保存失败（把目录设成只读，或者用一个是文件而不是目录的路径），内存数据保持原样
