# W-3 加水印流程（E1、E2、E3、E4）

- **基线分支**：`t-w-2`（叠在 W-2 上面），工作分支 `t-w-3`
- **先读**：`docs/tasks/W-COMMON.md`，以及 wizard.md 第 4 节中 E1–E4 和进度页的部分，ui-copy 第三节
- **范围**：`src/win/start.rs`、`assets/blindmark.rc.in`

## St 新增字段
```rust
files: Vec<PathBuf>,
note: String,
out_same_dir: bool,          // 默认 true；如果 ctx.cfg.out_dir 不为空，默认 false，并把它填进输入框
out_dir: String,
jpeg: bool,                  // 默认取 ctx.cfg.jpeg
strength: f32,               // 默认取 ctx.cfg.strength
run: Option<RunState>,       // 后台任务的状态：rx、cancel、total、done、results
results: Vec<(PathBuf, Result<EmbedOk, UserError>)>,
stopped: bool,
```
`files` 的初始值是 `ctx.embed_files`。

## 页面
**E1（230）**
- ListView 三列：文件名、尺寸、位置。尺寸用 `image::image_dimensions` 读，读不出来就显示“—”。
- 按钮：「添加图片…」「添加文件夹…」「移除」。用 `DragAcceptFiles` 支持把文件或文件夹拖进来；文件夹只取第一层，按 `IMAGE_EXTS` 过滤。同一个文件不重复添加。
- 列表为空时，在列表中间显示灰色提示文字。
- PSN_WIZNEXT 时如果列表为空：在页面内用红字提示，并停在这一页。

**E2（231，提交页）**
- 控件按 ui-copy 来：备注（输入框里有灰色提示）、保存位置（两个单选项，外加输入框和「浏览…」）、格式（两个单选项），以及「高级」。
- 「高级」是一个复选按钮，用 `BS_PUSHLIKE` 或者普通按钮加 ▸/▾ 都可以。点一下就展开或收起下面那一行强度滑块。默认收起。
- 强度滑块范围 15–40，旁边的标签显示“{档位}（{数值:.1}）”，档位的分界见 ui-copy。
- 选“指定文件夹”但输入框为空时：在页面内用红字提示，并停在这一页。
- **E2 上的改动只保存在 St 里，不写回全局设置。**
- 返回上一页再回来时，已经填的内容要保持原样（控件只在 WM_INITDIALOG 时创建一次，之后的值都存在 St 里）。

**E3（232，进度页）**
- PSN_SETACTIVE 时：清空 history，启动后台线程调用 `jobs::run_embed`，按钮全部禁用（取消按钮除外）。
- 每收到一个 `Running { index }`，就把进度文字更新为“正在处理 {name}（{done}/{total}）…”。
- 每收到一个 `Item`，就把结果存进 `results`，进度条加一格。
- `run_embed` 返回 Err（比如登记表打不开或者不配对）时，把每张图都记成同样的这个错误，然后照常进入完成页。
- 结束后按 W-COMMON 的规则自动进入 E4。停止的处理也按 W-COMMON。

**E4（233，完成页）**
- 标题有三种情况（见 ui-copy）：全部成功／部分没有处理／已停止。
- 下面是结果 ListView，两列：图片、结果。成功的结果写“编号 0x{id:08x}，保存为 {输出文件名}”，失败的结果写 `{message}`。
- 按钮：「打开所在文件夹」（打开第一个成功结果所在的文件夹）、「在登记表中查看」（参数是所有成功的编号）、「转到“加水印”选项卡」，再加上教学提示那一行。
- 没有任何一张成功时，前两个按钮要禁用。
